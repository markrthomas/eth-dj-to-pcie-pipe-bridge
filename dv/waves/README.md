# dv/waves — per-test GTKWave sessions

- `<test>.gtkw` — one session per test (smoke, tx, loop, pm, rxovf, scen, upf),
  generated by `wave_check.py gen` (edit the signal list there, not the .gtkw).
- `wave_dump.sv` — optional second top that dumps `<tb>`, `<tb>.dut`,
  `<tb>.dut.u_ctrl` (depth 1) to VCD; compiled in with `WAVES=1`.
- `wave_check.py check <test> <vcd>` — every session signal must exist in the dump
  and the clocks/reset/state must toggle; if gtkwave + xvfb-run are installed it
  also loads the session headless (`gtkw_count.tcl`) and requires every trace to
  resolve.

`make wave-<test>` runs the test with a dump, checks it, and opens GTKWave when a
display is available. `make waves` = `wave-loop`. `make wave-check-all` checks all
seven sessions without a GUI. The Verilator env has its own FST trace
(`make -C dv/vlt trace`); no .gtkw is provided for it.
